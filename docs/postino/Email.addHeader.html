    Function Email.addHeader

    Adds a custom header, e.g. List-Unsubscribe, In-Reply-To, References or X-Mailer. The same header can be added more than once; headers are written in the order they are added. Non-ASCII values are encoded according to RFC 2047.

    Email addHeader(
      string name,
      string value
    ) return;

    The headers that postino writes itself can't be added: MIME-Version, Date, Message-ID, From, To, Cc, Bcc, Reply-To, Subject and the Content-* headers.

    Parameters

    NameDescription
    name Header name, e.g. "List-Unsubscribe"
    value Header value, without CR or LF

    Returns

    Reference to this Email object for method chaining

    Throws

    PostinoException if the name is not valid or is reserved, or the value contains CR, LF or NUL

    Example

    email.addHeader("List-Unsubscribe", "<https://example.com/unsubscribe?id=42>, <mailto:unsubscribe@example.com>")
     .addHeader("List-Unsubscribe-Post", "List-Unsubscribe=One-Click");
