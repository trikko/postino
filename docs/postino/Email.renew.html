    Function Email.renew

    Makes the next send() or save() build a new message: new Date, Message-ID and boundaries, and the files of attachFile() and embedFile() are read again. Without it, send() and save() reuse the message built the first time, until a setter changes the email.

    Email renew() return pure nothrow @nogc @safe;

    Returns

    Reference to this Email object for method chaining

    Example

    email.send(url, user, password);    // message A
email.save("sent/a.eml");           // the same message A
email.renew().send(url, user, password); // message B, with a new Message-ID
