    Function Email.save

    Saves the email as a .eml file to the specified path. The .eml format is a standard email format that can be opened by most email clients. The file contains exactly the message that send() would deliver: Bcc recipients are not in it.

    Email save(
      scope string path
    );

    Parameters

    NameDescription
    path The file path where the .eml file will be saved

    Returns

    Reference to this Email object for method chaining

    Throws

    Exception if the email has no sender or no recipients, if a file to attach is missing, or if the file cannot be written to the specified path

    Example

    email.setFrom("sender@example.com")
     .addTo("recipient@example.com")
     .setSubject("Test Email")
     .setPlainTextBody("Hello World!")
     .save("/path/to/email.eml");
