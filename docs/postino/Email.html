    Class Email

    An email message. Every setter returns the same object, so calls can be chained. Addresses are checked when they are added; send() delivers to every To, Cc and Bcc recipient, and save() writes the same message as an .eml file.

    class Email;

    Methods

    NameDescription
    addAttachment (data, mimeType, name) Attaches data from memory to the email. The data is copied: changing the array afterwards does not change the email. For text, pass text.representation (from std.string).
    addAttachment (path, mimeType, name) Old name of attachFile(). A string given here is always read as a file path, never used as data.
    addBcc (address, name) Adds a recipient to the email's "Bcc" (Blind Carbon Copy) field. Multiple Bcc recipients can be added by calling this method multiple times. Bcc recipients receive the email but are never written in its headers, so the other recipients cannot see them.
    addCc (address, name) Adds a recipient to the email's "Cc" (Carbon Copy) field. Multiple Cc recipients can be added by calling this method multiple times. Cc recipients receive the email and are listed in the "Cc" header.
    addEmbeddedFile (data, cid, mimeType) Embeds data from memory in the email (inline attachment), to show it in the HTML body through its Content-ID. The data is copied: changing the array afterwards does not change the email.
    addEmbeddedFile (path, cid, mimeType) Old name of embedFile(). A string given here is always read as a file path, never used as data.
    addHeader (name, value) Adds a custom header, e.g. List-Unsubscribe, In-Reply-To, References or X-Mailer. The same header can be added more than once; headers are written in the order they are added. Non-ASCII values are encoded according to RFC 2047, which is right for unstructured headers (X-..., Comments, Keywords): in structured ones (List-Unsubscribe, In-Reply-To, References) use ASCII only, e.g. percent-encoded URLs.
    addTo (address, name) Adds a recipient to the email's "To" field. Multiple recipients can be added by calling this method multiple times.
    attachFile (path, mimeType, name) Attaches a file to the email. Attachments appear as downloadable files in the email client. The file is read when the email is sent or saved.
    clearAttachments () Removes every file added with addAttachment().
    clearBcc () Removes every recipient added with addBcc().
    clearCc () Removes every recipient added with addCc().
    clearEmbeddedFiles () Removes every file added with addEmbeddedFile().
    clearHeaders () Removes every header added with addHeader().
    clearTo () Removes every recipient added with addTo().
    clone () Returns a copy of this email, to change it without touching the original: for example the same message for many recipients, one at a time. The copy shares the data of the attachments added from memory, so don't modify those arrays.
    embedFile (path, cid, mimeType) Embeds a file in the email (inline attachment), to show it in the HTML body through its Content-ID: <img src="cid:logo">. The file is read when the email is sent or saved.
    save (path) Saves the email as a .eml file to the specified path. The .eml format is a standard email format that can be opened by most email clients. The file contains exactly the message that send() would deliver: Bcc recipients are not in it.
    send (smtpServerUrl, username, password, smtp) Sends the email using the specified SMTP server. The email is delivered to every To, Cc and Bcc recipient.
    send (smtpServerUrl, username, auth, smtp) Sends the email authenticating with an OAuth 2.0 access token (SASL XOAUTH2), as Gmail and Microsoft 365 require when passwords are not allowed. Getting and refreshing the token is up to you; postino only sends it.
    setFrom (address, name) Sets the sender's email address and optional display name.
    setHtmlBody (body) Sets the HTML body of the email. This allows for rich formatting, images, and styling.
    setPlainTextBody (body) Sets the plain text body of the email. This will be displayed in email clients that don't support HTML.
    setReplyTo (address, name) Sets the "Reply-To" email address for the email. This determines where replies to this email will be sent.
    setSubject (subject) Sets the email subject line. The subject will be automatically encoded if it contains non-ASCII characters.
