    Function Email.addEmbeddedFile

    Embeds data from memory in the email (inline attachment), to show it in the HTML body through its Content-ID. The data is copied: changing the array afterwards does not change the email.

    Email addEmbeddedFile(
      scope const(ubyte)[] data,
      string cid,
      string mimeType
    ) return;

    Parameters

    NameDescription
    data The content, e.g. the bytes of a PNG image
    cid Content-ID for referencing in HTML (e.g., "chart" for src="cid:chart")
    mimeType MIME type of the data (e.g., "image/png")

    Returns

    Reference to this Email object for method chaining

    Throws

    PostinoException if cid or mimeType are not valid

    Example

    email.addEmbeddedFile(png, "chart", "image/png")
     .setHtmlBody("<img src='cid:chart'>");
