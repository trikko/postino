    Function Email.addAttachment

    Attaches data from memory to the email. The data is copied: changing the array afterwards does not change the email. For text, pass text.representation (from std.string).

    Email addAttachment(
      scope const(ubyte)[] data,
      string mimeType,
      string name = null
    );

    Parameters

    NameDescription
    data The content of the file
    mimeType MIME type of the data (detected from the extension of name if empty)
    name File name shown to the recipient (a random one if not provided)

    Returns

    Reference to this Email object for method chaining

    Throws

    PostinoException if mimeType or name are not valid

    Example

    import std.string : representation;
email.addAttachment(pdfBytes, "application/pdf", "invoice.pdf")
     .addAttachment(csv.representation, "text/csv", "orders.csv");
