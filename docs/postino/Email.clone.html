    Function Email.clone

    Returns a copy of this email, to change it without touching the original: for example the same message for many recipients, one at a time. The copy shares the data of the attachments added from memory, so don't modify those arrays.

    Email clone();

    Example

    auto newsletter = new Email()
    .setFrom("news@example.com")
    .setSubject("News")
    .setHtmlBody(html);

auto smtp = SMTP(); // the same SMTP object reuses the connection

foreach (subscriber; subscribers)
    newsletter.clone()
        .addTo(subscriber.email, subscriber.name)
        .addHeader("List-Unsubscribe", "<https://example.com/unsubscribe?id=" ~ subscriber.id ~ ">")
        .send("smtp://smtp.example.com:587", "user", "password", smtp);
