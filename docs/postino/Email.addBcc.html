    Function Email.addBcc

    Adds a recipient to the email's "Bcc" (Blind Carbon Copy) field. Multiple Bcc recipients can be added by calling this method multiple times. Bcc recipients receive the email but are never written in its headers, so the other recipients cannot see them.

    Email addBcc(
      string address,
      string name = null
    ) return;

    Parameters

    NameDescription
    address The Bcc recipient's email address
    name Optional display name for the recipient

    Returns

    Reference to this Email object for method chaining

    Throws

    Exception if the address is not a valid email address

    Example

    email.addBcc("archive@example.com", "Email Archive")
     .addBcc("backup@example.com");
