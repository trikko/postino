    Function Email.send

    Sends the email using the specified SMTP server. The email is delivered to every To, Cc and Bcc recipient.

    bool send(
      string smtpServerUrl,
      string username = null,
      string password = null,
      std.net.curl.SMTP smtp = opCall()
    );

    Use "smtps://" for implicit TLS (usually port 465) and "smtp://" for plain SMTP (port 25) or STARTTLS (usually port 587). With "smtp://" and a username and password, STARTTLS is required, so the credentials never travel in clear: the server must support it, or send() throws. Servers on localhost are the exception.

    Parameters

    NameDescription
    smtpServerUrl SMTP server URL (e.g., "smtps://smtp.gmail.com:465" or "smtp://smtp.example.com:587")
    username SMTP authentication username (optional)
    password SMTP authentication password (optional)
    smtp Pre-configured SMTP object (optional)

    Returns

    true if the email was sent successfully

    Throws

    Exception if the email has no sender or no recipients, if a file to attach is missing, or if the SMTP operation fails (CurlException)

    Example

    email.send("smtps://smtp.gmail.com:465", "user@gmail.com", "app_password");
email.send("smtp://smtp.example.com:587", "user", "password"); // STARTTLS
email.send("smtp://localhost:25"); // No authentication
