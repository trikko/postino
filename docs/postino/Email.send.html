    Function Email.send

    Sends the email using the specified SMTP server. The email is delivered to every To, Cc and Bcc recipient.

    bool send(
      string smtpServerUrl,
      string username = null,
      string password = null,
      std.net.curl.SMTP smtp = opCall()
    );

    Use "smtps://" for implicit TLS (usually port 465) and "smtp://" for plain SMTP (port 25) or STARTTLS (usually port 587). With "smtp://" and a username and password, STARTTLS is required, so the credentials never travel in clear: the server must support it, or send() throws. Servers on localhost are the exception.

    Pass the same smtp object to many sends to reuse the connection. Each send sets its own credentials on it, or none: those of a previous send are never reused.

    Parameters

    NameDescription
    smtpServerUrl SMTP server URL (e.g., "smtps://smtp.gmail.com:465" or "smtp://smtp.example.com:587")
    username SMTP authentication username (optional)
    password SMTP authentication password (optional)
    smtp Pre-configured SMTP object (optional)

    Returns

    true if the email was sent successfully

    Throws

    PostinoException if the URL is not valid (credentials, "?" or "#" in it), if the email has no sender or no recipients, or if a file to attach is missing or unreadable; CurlException if the connection, TLS, authentication or the SMTP operation fails

    Example

    email.send("smtps://smtp.gmail.com:465", "user@gmail.com", "app_password");
email.send("smtp://smtp.example.com:587", "user", "password"); // STARTTLS
email.send("smtp://localhost:25"); // No authentication

    Function Email.send

    Sends the email authenticating with an OAuth 2.0 access token (SASL XOAUTH2), as Gmail and Microsoft 365 require when passwords are not allowed. Getting and refreshing the token is up to you; postino only sends it.

    bool send(
      string smtpServerUrl,
      string username,
      OAuth2 auth,
      std.net.curl.SMTP smtp = opCall()
    );

    As with the password version, "smtp://" requires STARTTLS, except on localhost.

    Parameters

    NameDescription
    smtpServerUrl SMTP server URL (e.g., "smtp://smtp.office365.com:587" or "smtps://smtp.gmail.com:465")
    username The account the token belongs to, usually its email address
    auth The OAuth 2.0 access token, as OAuth2(token)
    smtp Pre-configured SMTP object (optional)

    Returns

    true if the email was sent successfully

    Throws

    PostinoException if username or the token are empty, if the URL is not valid, if the email has no sender or no recipients, or if a file to attach is missing or unreadable; CurlException if the server refuses the token or the SMTP operation fails

    Example

    email.send("smtp://smtp.office365.com:587", "user@example.com", OAuth2(accessToken));
