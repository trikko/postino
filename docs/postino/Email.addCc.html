    Function Email.addCc

    Adds a recipient to the email's "Cc" (Carbon Copy) field. Multiple Cc recipients can be added by calling this method multiple times. Cc recipients receive the email and are listed in the "Cc" header.

    Email addCc(
      string address,
      string name = null
    ) return;

    Parameters

    NameDescription
    address The Cc recipient's email address
    name Optional display name for the recipient

    Returns

    Reference to this Email object for method chaining

    Throws

    PostinoException if the address is not a valid email address

    Example

    email.addCc("manager@example.com", "Project Manager")
     .addCc("team@example.com");
